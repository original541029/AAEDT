網站無障礙聲明

初版方案

社團法人台灣可及環境設計協會（以下簡稱本會）致力於提升生活品質的承諾以及響應聯合國推動數位無障礙空間的理念，於本會網站上導入並執行數位無障礙設計，以確保所有訪客，無論是否有身心障礙，都可以有平等的用戶體驗。

2025年2月25日、2025年3月30日立婷修

支持無障礙的措施

本會採取以下措施，確保網站無障礙性：

  • 將無障礙納入我們的使命聲明中。
  • 將無障礙納入所有網站內容的基本要求。內容必須符合 WCAG 2.1 AA 級。
  • 與國際認證的無障礙專家合作提供相應指導與知識。
  • 確保內容編寫者具備無障礙相關知識與技能。
  • 為員工提供無障礙教育訓練。
  • 在設計使用者角色時納入身心障礙者的人物誌。
  • 在此頁面詳解數位無障礙環境的重要性。

符合標準的狀態

Web Content Accessibility Guidelines（WCAG）是為提升身心障礙者可近性的國際標準。其合規性分為三個等級：A、AA 與 AAA。

「完全符合」指內容在該級別下無任何例外地符合所有 WCAG 要求。

  • 詳細狀態需等網站做完後的評估報告。

意見回饋

我們歡迎您對本會網站的無障礙功能提供意見。如您遇到任何障礙，請與我們聯繫：

  • E-mail：contact@oadrc.com

一般我們會在 3–5 個工作日內回覆無障礙相關信件。有時可能需時最多 3 週。

與瀏覽器及輔助技術的相容性

本會網站設計支援最新兩個版本的主流瀏覽器及各種輔助技術。

若使用 Internet Explorer 10、11 或更早版本，部分功能可能無法正常顯示。本網站不支援 Internet Explorer 9 及更早版本。

技術規格

本網站符合 WCAG 2.1 標準所依賴的技術包括：

  • HTML
  • WAI-ARIA
  • CSS
  • SVG

為提升無障礙與使用者體驗，亦使用：

  • JavaScript

限制與替代方案

  • 網站上的某些影片透過 YouTube 提供。
  • 網站地圖使用 Google 地圖。
  • 部份表單使用 Google 表單。

評估方法

本會透過與國際認證的無障礙專家合作檢測網站的無障礙性。

數位無障礙環境的重要性

在日常生活中，透過手機，科技的使用已經與我們密不可分，您可能會從朋友及家人的分享中，甚至自己在使用網站時碰到過以下幾種情境：這網頁字體為什麼不能放大？這顏色太淡我看不清楚。這個關閉廣告的按鈕怎麼都點不到？這麼多的圖標按鈕，哪個才是我要選的？這個圖的字也太小，我下載放大以後就看不清楚了，這到底在寫甚麼？我表單的內容都填完了，為什麼發送不出去？

以上這些情形，都是該網站沒有將數位無障礙環境考量進去的結果，數位無障礙環境並非只針對身心障礙人士，而是以人為本的數位設計和編程理念，此理念和可及／包容設計與通用設計是相通的。如果一個表單只使用紅色或綠色表示通過或有錯誤，對有紅綠色盲的訪客，這對他們有實際使用上的障礙，但是當通過的欄位增加勾勾，以及錯誤欄位增加Ｘ並提供修改信息，這不單單解決有色覺偏差的訪客，同時也大幅度提升所有訪客在輸入表單時的用戶體驗。

另一個範例為一張缺少替代文字的流程圖圖象，這對使用螢幕閱讀器的訪客（如視障人士）會造成極大障礙，因為螢幕閱讀器會朗讀該圖象的網址從 "http" 開始一個字母一個字母朗讀。除此之外，流程圖或其它含有文字的圖片，其本身的問題還有在手機上會看不清楚文字，對所有使用手機的訪客而言，他們會非常困擾如何取得圖片內的資訊。此問題的解決方式之一，即是在同個頁面上透過 HTML 提供實際的文字內容，並且在相應的標題使用正確的 HTML 標籤，這樣不只解決螢幕閱讀器用戶的問題，也更加改善手機用戶在瀏覽訊息的困擾，因為手機自己就會將 HTML 的文字適應到手機版的網頁上。除此之外，SEO 在做排名的時候也會根據 HTML 的架構而給出更高的排名。

如果以上幾個範例發生在重要網站上，如報稅、銀行、保險、醫療、健保或網購等頁面上，這是嚴重影響到身心障礙人士的實際人權問題，漠視數位無障礙環境的網站實際上不只在剝奪身心障礙人士平等且獨立獲得信息的權利，也在侵犯他們履行國民責任的義務或獨立完成事情的隱私。

數位無障礙空間在國際上是人權議題。

世界衛生組織（WHO）的數據顯示全世界有 16% 的人口在經歷顯著的身心障礙，以這數據為準，這代表台灣約有 3,700,000 人在經歷顯著的身心障礙。而在 WHO 的報告 Ageing and disability 中，60 歲以上的長者當中有 46% 的人有身心障礙，這大約是 2,050,000 台灣人口，這數據也代表我們若不從現在開始重視數位無障礙環境，待歲數增長至 60 歲才開始重視此議題，將會遲於解決問題。

可及設計一詞源自英文 Accessible Design，其意思是讓所有人可到達、可使用，並符合安全又便利原則的設計。本會致力於推廣可及觀念，並落實於教育培訓、環境改善、規劃設計與工程施工等項目之中，以創造更安全便利的生活環境。數位無障礙環境的理念與我們所承諾的品質生活以及訪客拜訪網站的體驗，也是本會極為重視的一部份。也因此在本網站導入數位無障礙理念。

讓我們為未來的自己打造數位友善的環境。
